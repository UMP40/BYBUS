# BYBUS v1.0 / 内部版本 23：个性化字体修复

2026-09-29，vivo X100 Ultra / OriginOS 6 / Android 16，游戏 1.115.0 / 475。

## 原因与修改

个性化断句预览把零协 `IntroductionPreset` 中的 `{0}` 替换为五个实心方块 `■■■■■`。
旧的字体来源判定只接受数字、时间和已知名称参数，因此没有识别完整预览句，
部分汉字继续使用日文主字体，其余汉字由中文粗体补齐，造成同一句深浅不一。

现在允许这一已观察到的固定预览参数，但必须同时匹配零协完整句式。
不改显示内容；单独方块、其他方块数量、未知名字、残缺句子或危险字体标签
都不能由该规则获得中文主字体身份。继续使用原有的零协 Sarasa Gothic SC Bold
及材质转换，不新增字体包，不把普通玩家输入按中文强制换字体。

## 实际验证

- 有关预览句、彩色标签、方块数量、未知名字、追加正文和重复参数一致性的
  native 定向断言在手机通过；未重跑完整业务测试。
- 四条原先深浅混排的断句已直接观察为一致粗体。相应原生记录共 53 条，
  均识别译文来源并切换中文主字体，材质与字重指标一致。
- 首屏九个词语逐项查看，显示一致；词语的专用诊断记录没有命中，
  因此这里只记视觉检查，不声称具有同等元数据证据，也不声称修复了未复现的词语问题。
- 本轮共两次签名 Release 构建、两次覆盖安装、两次游戏启动。
  第二次是因为 vivo 不向 ADB 提供所需应用日志而补充私有诊断；最终 APK
  与完成字体观察的 APK 使用字节完全相同的原生库，没有为重复观察再次启动。
  两次启动均到达主界面，分别观察进程持续 30 秒，登录及资源保留。
- 最终构建包含 lintVital；签名、原生库与 ZIP 的 16 KiB 对齐、内置资源哈希通过。
  这是打包验证，不等于增加了此前未验证的设备兼容范围。

未逐页检查全部断句、词语、剧情或其他游戏界面；没有把本次样本当作全游戏字体验收。
界面布局未改，平板结果沿用内部版本 22 的窗口检查，未连接平板真机。
游戏截图只保留在私有临时目录，交付目录不包含账号页面。

# BYBUS v1.0.4

[下载 Android ARM64 安装包](https://github.com/gravere/BYBUS/releases/download/v1.0.4-build.47/BYBUS-v1.0.4-arm64-v8a.apk)

## 更新内容

- 修复下载提示中带 MB、GB 等容量参数的中文未统一字体，以及已知段落拼接后丢失字体识别的问题。
- 修复浏览多个页面后新增文字样式丢失描边的问题，并在组件销毁后释放不再使用的字体材质。
- 旧文字组件优先使用经过动态字体和中文字形检查的内置粗体；加载失败时使用加粗的系统后备字体，并保留斜体与样式恢复。

## 安装

下载 `BYBUS-v1.0.4-arm64-v8a.apk`，覆盖安装即可保留游戏资源与配置。首次使用请阅读[使用说明](https://github.com/gravere/BYBUS#开始使用)。

v1.0 用户请手动覆盖安装本版一次，之后可继续在应用内更新。

附件中的 `BYBUS.apk` 用于应用内更新，与带版本的安装包内容一致。校验值见 `SHA256SUMS.txt`。

## 验证范围

本版完成本地构建、字体与材质针对性回归检查和安装包校验；尚未完成真机画面验证，旧文字组件最终选择的字体取决于运行时检查结果。

# BYBUS v1.0.5

**首次安装或手动更新，请下载完整 APK：**

[下载 BYBUS v1.0.5 · Android ARM64 完整安装包](https://github.com/gravere/BYBUS/releases/download/v1.0.5-build.48/BYBUS-v1.0.5-arm64-v8a.apk)

## 更新内容

- 加入应用内增量更新：后续发行版有匹配补丁时，优先下载差异内容，自动合成并校验安装包。
- 更新页面显示下载方式、实际下载大小和合成进度；补丁不可用时自动回退完整包，取消下载不会触发回退。
- 保留完整 APK 下载入口，覆盖安装继续保留游戏资源、登录和设置。

## 这次如何更新

**本版是增量更新支持的起点，仍需完整下载安装一次。** v1.0.4 及更早版本不能读取差异补丁，因此本次不提供 `.delta` 附件。升级到本版后，后续有匹配补丁的发行版即可使用增量下载；跨越未提供补丁的旧版本时仍下载完整包。

v1.0 用户请手动下载完整 APK 覆盖安装。其他旧版可在「设置与工具 → 更新」中升级。不要卸载旧版。

## 附件怎么选

| 文件 | 用途 |
| --- | --- |
| `BYBUS-v1.0.5-arm64-v8a.apk` | 完整安装包，首次安装和手动更新选择此文件 |
| `BYBUS.apk` | 同一完整安装包的自动更新兼容名称，不必重复下载 |
| `bybus-update.json`、`SHA256SUMS.txt` | 更新元数据与校验值，不是安装包 |
| GitHub 的 Source code 文件 | 项目源码，不是安装包 |

后续发行版可能附带 `.delta` 文件，仅供 BYBUS 自动处理，不能单独安装。增量更新减少下载量，合成与覆盖安装仍需完整 APK 的临时空间。首次使用请阅读[使用说明](https://github.com/gravere/BYBUS#开始使用)。

## 验证范围

本版进行更新流程的本地回归、真实签名 APK 的补丁生成与跨语言还原校验，以及正式安装包检查；未进行手机安装和交互验证。

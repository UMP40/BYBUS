# BYBUS v1.0

[下载 Android ARM64 安装包](https://github.com/gravere/LimbusZhLauncher/releases/download/v1.0-build.43/BYBUS-v1.0-arm64-v8a.apk)

## 更新内容

- 重新设计设置与更新页面的图标，区分不同功能，修正箭头与圆弧重叠。
- 简化更新页面的装饰，统一图标尺寸、线宽与配色。
- 修复应用更新下载完成后无法打开系统安装器的问题。

## 安装

下载 `BYBUS-v1.0-arm64-v8a.apk`，直接覆盖安装以保留游戏资源与配置。首次使用请阅读[使用说明](https://github.com/gravere/LimbusZhLauncher#开始使用)。

构建 41 / 42 的用户需手动覆盖安装本版一次，以修复应用内安装入口。

附件中的 `BYBUS.apk` 供旧版自动更新使用，内容与带版本的安装包一致，只需安装其中一个。文件校验值见 `SHA256SUMS.txt`。

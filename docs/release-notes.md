# BYBUS v1.0.6

**首次安装或手动更新，请下载完整 APK：**

[下载 BYBUS v1.0.6 · Android ARM64 完整安装包](https://github.com/gravere/BYBUS/releases/download/v1.0.6-build.49/BYBUS-v1.0.6-arm64-v8a.apk)

## 更新内容

- 修复检查更新反复提示“刚刚检查过”：手动检查可立即刷新，不再被本地成功缓存挡住。
- 修复普通 HTTP 错误被误判为长时间限流，并清除旧版遗留的错误等待状态。
- 真实限流显示剩余等待时间，到期后恢复按钮；成功检查清除持久等待，补丁下载遇到限流时暂停请求。

## 这次如何更新

**v1.0.5 可在应用内通过差异补丁升级本版。** 若旧版更新页一直显示“刚刚检查过”，可直接下载上方完整 APK 覆盖安装，安装后旧的错误等待状态会自动清理。

v1.0.4 及更早版本需下载完整包；v1.0 用户请手动下载。覆盖安装保留游戏资源、登录和设置，不要卸载旧版。

## 附件怎么选

| 文件 | 用途 |
| --- | --- |
| `BYBUS-v1.0.6-arm64-v8a.apk` | 完整安装包，首次安装和手动更新选择此文件 |
| `BYBUS.apk` | 同一完整安装包的自动更新兼容名称，不必重复下载 |
| `BYBUS-update-48-to-49.delta` | v1.0.5 到本版的差异补丁，仅供应用自动处理，不能独立安装 |
| `bybus-update.json`、`SHA256SUMS.txt` | 更新元数据与校验值，不是安装包 |
| GitHub 的 Source code 文件 | 项目源码，不是安装包 |

增量更新减少下载量，合成与覆盖安装仍需完整 APK 的临时空间。首次使用请阅读[使用说明](https://github.com/gravere/BYBUS#开始使用)。发行文件保留最近三个正式构建。
